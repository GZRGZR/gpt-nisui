# מחשבון גימטריה עברית

מחשבון גימטריה קטן ומהיר שעובד כולו בדפדפן.

## יכולות
- גימטריה רגילה
- מספר גדול: ך=500, ם=600, ן=700, ף=800, ץ=900
- מספר סידורי
- גימטריה קטנה
- פירוט ערך כל אות
- השוואה בין שני ביטויים
- בדיקה מול מספר יעד
- ממשק עברי RTL
- ללא שרת וללא שליחת הטקסט החוצה
